# 布料模拟游戏

基于物理引擎的2D布料交互游戏，玩家可以通过不同工具与NPC的衣服进行互动。

## 功能特性

### 三大核心系统

1. **身体碰撞系统（胶囊体）**
   - 使用胶囊体表示人体的四肢和躯干
   - 防止衣服穿透身体
   - 支持自定义姿势和体型
   - 可拖拽调整胶囊体位置和大小

2. **布料模拟系统**
   - 基于质点弹簧模型的物理模拟
   - 支持绘制自定义衣服轮廓
   - 自动生成内部网格结构
   - 可调节布料弹性参数
   - 支持布料撕裂效果

3. **交互工具系统**
   - **手**：抓取并拖拽布料
   - **小刀**：切割布料
   - **风场**：吹动布料

## 使用方法

### 1. 身体编辑模式
- 点击"添加胶囊体"按钮
- 在画布上拖拽创建胶囊体来构建人体模型
- 点击选中胶囊体，拖动端点调整位置
- 按Delete键删除选中的胶囊体
- 可以导入照片作为参考背景

### 2. 衣服编辑模式
- 点击"绘制衣服"按钮
- 在画布上点击绘制闭合轮廓
- 双击或右键完成绘制
- 系统自动生成布料网格
- 调节弹性系数改变布料特性

### 3. 游戏模式
- 选择工具与衣服互动：
  - **手**：点击拖拽布料
  - **小刀**：划过衣服进行切割
  - **风场**：移动鼠标吹动衣服
- 空格键暂停/继续模拟

## 技术实现

- **纯JavaScript**实现，无需外部依赖
- **Canvas 2D渲染**
- **Verlet积分法**进行物理模拟
- **约束求解**保持布料结构
- **胶囊体碰撞检测**防止穿透

## 运行项目

直接在浏览器中打开 `index.html` 文件即可运行。

建议使用本地服务器：
```bash
# 使用Python
python -m http.server 8000

# 或使用Node.js
npx serve
```

然后访问 `http://localhost:8000`

## 快捷键

- **空格**：暂停/继续
- **Delete**：删除选中的胶囊体

## 性能优化建议

- 当前使用Canvas 2D渲染，适合中等复杂度的布料
- 如需更复杂的布料效果，可以升级到WebGL渲染
- 布料网格密度可通过修改 `cloth-simulation.js` 中的 `resolution` 参数调整
